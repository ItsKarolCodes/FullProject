Aplicación Full Stack de videoclub desarrollada con React y Express. Incluye catálogo de películas, gestión de favoritos, y sistema de comentarios para convertirte en un critico del cine.

TECNOLOGIAS USADAS

**Frontend:**
- React + Vite
- CSS / Tailwind 

**Backend:**
- Node.js
- Express
- MongoDB / SQL (Pon tu base de datos)
